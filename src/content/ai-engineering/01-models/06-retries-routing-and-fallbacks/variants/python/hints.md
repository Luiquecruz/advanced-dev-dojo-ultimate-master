Build bottom-up. `is_retryable` is one line: an `isinstance(error, ModelError)` check plus a set of statuses. `retry_delay` returns `error.retry_after_ms` when it is not `None`, else the full-jitter formula. `generate_with_retry` is a retry loop with `retry_delay` as the delay.
---
In `generate_with_retry`, loop over attempts (`for attempt in itertools.count():`) with `try: return await model.generate(request)` and `except Exception as error:`. In the `except`, re-raise with a bare `raise` when `attempt >= options.retries` or the error is not retryable; otherwise `await options.sleep(retry_delay(attempt, error, options))`. `generate_with_fallback` wraps one `generate_with_retry` call in a `try`, re-raises non-retryable errors and calls `generate_with_retry` on the backup for the rest.
---
For `answer`, put the cheap attempt in a helper that returns the text when the call succeeded and `validate` accepted it, and `None` in every other case (a caught exception included). If you got text, return it with `"escalated": False`. Otherwise call `generate_with_fallback(strong, backup, ...)`, validate its text, and either return it with `"escalated": True` and the answering model's name or raise `InvalidAnswerError`.
