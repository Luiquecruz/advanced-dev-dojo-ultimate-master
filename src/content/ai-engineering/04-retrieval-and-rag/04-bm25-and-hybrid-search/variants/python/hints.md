Precompute once in `Bm25Index.__init__`: for every document a dict from token to count, its token count, the average token count, and a dict from token to the number of documents that contain it. With those, `idf` is one line of `math.log` and a document's score is a sum over the unique query tokens (`list(dict.fromkeys(tokenize(query)))` keeps first occurrences in order).
---
Write the per-term contribution exactly as the formula reads: `idf * tf * (k1 + 1) / (tf + k1 * (1 - b + b * length / average_length))`. A token that is absent from the document has `tf = 0`, so it adds 0. `search` builds `{"id", "score"}` for every document, keeps `score > 0`, sorts with `sorted(..., key=lambda result: result["score"], reverse=True)` (the sort is stable, so ties keep document order) and slices.
---
For RRF, keep a dict of id to score; a dict remembers insertion order, which gives the tie rule for free. Inside each ranking, track a `set` of ids already seen and add `1 / (k + position + 1)` only the first time. For `hybrid_search`, wrap each call in a small coroutine that awaits the result when `inspect.isawaitable(result)`, then `asyncio.gather(..., return_exceptions=True)` turns every raised error into a value you can recognize with `isinstance(outcome, Exception)` and skip.
