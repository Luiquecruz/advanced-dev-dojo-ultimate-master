Write one `adjacency(graph)` helper that returns a dict from id to the list of neighbor ids (both directions, no duplicates, no self-loops, only known ids). Use lists rather than sets: a list keeps the order relations connect the nodes, which the local neighborhood relies on. Communities, fallback degrees and local neighborhoods all use it. For the edge weight, count the ids of one neighbor list that are `in` the other, plus one.

Track a `changed` flag per pass. At the end group ids by label with `setdefault` (ids are already sorted, so members come out sorted) and sort the groups with the key `(-len(members), members[0])`.
