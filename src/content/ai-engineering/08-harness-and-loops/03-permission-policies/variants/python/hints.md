Start with the two matchers, because everything else is built on them. Both become a regular expression matched with `re.fullmatch`: escape every literal character with `re.escape`, then translate the wildcards. For commands, `*` is `.*` (`".*".join(re.escape(part) for part in pattern.split("*"))`). For paths, translate `**/` to `(?:.*/)?`, `**` to `.*`, `*` to `[^/]*` and `?` to `[^/]`, and normalize the path with `posixpath.normpath` before testing it.
---
A path is outside the project when its normalized form starts with `/`, equals `..` or starts with `../`. Check that in `matches_path` (return `False`) and again at the top of `evaluate` for `Read`, `Edit` and `Write` (return `deny` with no rule). `split_command` is one `re.split(r"&&|\|\||;|\||\n", command)` followed by `strip()` and a filter on empty parts.
---
In `evaluate`, write a helper that handles one call: loop over `["deny", "ask", "allow"]`, find the first rule of that list for which `rule_matches(rule, call)` is true, and return it. `rule_matches` parses `Tool(pattern)`, matches the tool name with the command matcher (so `*` works), returns `True` for bare rules and otherwise picks `matches_path` or `matches_command` from the tool.
---
For `Bash`, run the helper on every part of `split_command` (copying the call with `{**call["arguments"], "command": part}`) and keep the result with the highest severity, replacing it only when a later part is strictly more severe. In `review_tool_calls`, parse the arguments with `json.loads` inside `try`/`except ValueError` and accept only a `dict`; unknown tools and anything else become `deny` with `"rule": None`.
