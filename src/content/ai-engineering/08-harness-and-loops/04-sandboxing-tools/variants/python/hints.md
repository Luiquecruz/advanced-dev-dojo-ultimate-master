In the jail, compute one absolute `target` per call: `posixpath.normpath(posixpath.join(self.root, path))`. `join` keeps an absolute `path` as it is and prefixes a relative one with the root, and `normpath` resolves `..` and drops a trailing slash. Accept the target only when `target == self.root or target.startswith(self.root + "/")`. The separator is the whole point: without it, `/app/workspace-secrets` passes for `/app/workspace`.
---
In `check_egress`, call `urlsplit(url)` and read `parsed.port` inside one `try`/`except ValueError`, then work only with the parsed object: `scheme`, `username`, `password`, `port` and `hostname`. `urlsplit` does not canonicalize IPv4 addresses, so ask the platform: `socket.inet_aton(host)` succeeds for `127.0.0.1`, `0x7f000001`, `2130706433` and `127.1` alike and raises `OSError` for a name, and `ipaddress.IPv6Address(host)` recognizes `::1`.
---
For a wildcard entry such as `*.github.com`, keep the leading dot when comparing: `host.endswith(".github.com")`. That accepts `api.github.com` and rejects both `github.com` and `evilgithub.com`. Strip one trailing dot with `hostname.removesuffix(".")` before the IP, localhost and allowlist checks.
---
The fetch tool is a `while True` loop: check the current URL, `await fetch(current, redirect="manual")`, and return unless the status is a redirect with a `location` header. Otherwise raise once the redirect count reached `max_redirects`, and continue with `urljoin(current, location)`. In `execute_tool_call`, put the parsing and the dispatch inside one `try` and build the `Error:` message in `except Exception as error`, adding `error.code` for a `SandboxError`.
