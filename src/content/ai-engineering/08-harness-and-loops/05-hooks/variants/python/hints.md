Write two small helpers first. `matches_tool(matcher, name)` is `matcher == "*"` or a `split("|")` that contains the name. `with_timeout(work, timeout_ms)` calls `work()`, returns the value when it is not awaitable (`inspect.isawaitable`), and otherwise returns `await asyncio.wait_for(outcome, timeout_ms / 1000)`. Call it inside one `try`/`except Exception`, so raised exceptions, failing coroutines and `TimeoutError` are handled alike.
---
For pre-tool hooks, keep a `current` call and loop over the matching hooks. Validate each result: `continue`, `block` with a string `"reason"`, or `rewrite` with a dict `"arguments"`; anything else (including `None`) is a failure. Return `{"status": "blocked", "hook": hook.name, "reason": ...}` from inside the loop on a block or a failure, and replace `current` on a rewrite.
---
Call `execute(current)` outside any `try` (and await it when it returns an awaitable), so tool exceptions reach the caller unchanged. Then loop over the matching post-tool hooks with the same timeout and validation (`continue`, or `replace` with a string `"output"`); a failure returns `blocked` and the output is never returned.
---
The built-ins are a few lines each: `any(pattern.search(command) for pattern in DANGEROUS_COMMANDS)`; `min(timeout_ms, max_ms)` only when the value is an `int` or `float` (and not a `bool`); and a loop over `SECRET_PATTERNS` with `pattern.sub("[REDACTED]", output)`. In `run_tool_calls`, parse the arguments with `json.loads` inside `try`/`except ValueError`, accept only a `dict`, look the tool up with `tools.get`, then map the runner's result to the output or `Blocked by <hook>: <reason>`.
