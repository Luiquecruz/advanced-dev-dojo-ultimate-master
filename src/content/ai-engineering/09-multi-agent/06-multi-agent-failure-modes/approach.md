1. Put a verifier at every boundary between agents. Structured outputs make the check mechanical: finished, parseable, the expected shape, and claims that cite only sources the worker was given.
2. Turn failed validation into a precise retry, then into quarantine. Feedback names the problems; whatever still fails stays out of downstream context, so one hallucination cannot be laundered into a fact.
3. Protect independence procedurally: first-round votes run in parallel and see only the question. Counting against all voters makes abstentions weaken consensus instead of disappearing.
4. Discuss only on disagreement and share answers without names, then accept "no consensus" as a result to escalate.
5. Treat delegation like recursion: reject cycles, cap depth and fan-out per delegator, and cap the total per run, all before any model call is made.
