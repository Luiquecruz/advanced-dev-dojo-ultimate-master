Start with the scorers; each `score` method is a small pure function returning `{"pass", "score", "detail"}`. For `normalize_answer`, one regex anchored at both ends (`r"^[\s.,!?\"']+|[\s.,!?\"']+$"`) strips the edges, and `re.sub(r"\s+", " ", ...)` collapses the inside. Raise from the exact and semantic scorers when `eval_case.get("expected") is None`; the runner will turn that into a failed score.
---
In the schema scorer, wrap `json.loads` in its own `try`/`except ValueError`, so a JSON error and a schema error produce different details. `safe_parse(schema, value)` returns `{"success", "issues"}`; build the detail from the issues, joining each `issue["path"]` with dots and adding `issue["message"]`.
---
Split `run_eval` in two helpers. `run_case` puts only the model call inside `try`/`except Exception` (a failure returns `{"output": None, "error": str(error), "scores": {}, "pass": False}`) and then calls a `score_safely` helper per scorer, which calls `scorer.score(...)`, awaits the result when `inspect.isawaitable(result)`, all inside its own `try`/`except`. `summarize` counts over the case list; for `"byScorer"`, read `result["scores"].get(name)`, treating a missing score as a failure worth 0.
