Write `checkUrl` with `new URL()` inside a `try`, then check `protocol`, `username`/`password`, `port` and finally `hostname.toLowerCase().replace(/\.$/, '')` against the allowlist with `===`. Never use `includes` on the hostname: `docs.example.com.attacker.example` contains your domain.
---
For reference definitions, use a multiline regex such as `/^ {0,3}\[[^\]]+\]:[ \t]*<?([^\s>]+)>?.*$/gm` with `replace` and return `''` for lines you drop. For the one-pass part, build **one** regex with alternatives in this order: autolink `<(https?:\/\/[^>\s]+)>`, image, link, HTML tag `<\/?[a-z][^>]*>`, bare URL. The engine tries the alternatives left to right at each position, so `<https://...>` is an autolink, not a tag, and a URL inside `[text](url)` is consumed by the link alternative before the bare-URL one sees it.
---
Give the image and link alternatives capture groups for the text and the URL; in the `replace` callback, unmatched groups are `undefined`, so test `autolinkUrl !== undefined`, then `imageAlt !== undefined` (an empty alt is `''`), then `linkText !== undefined`, then `match.startsWith('<')` for HTML, and treat the rest as a bare URL. To strip an allowed image's query, copy the parsed URL, set `search` and `hash` to `''` and use `toString()`.
