Write `check_url` with `urlsplit(url)` and `parsed.port` inside a `try` (a malformed port raises `ValueError`), then check `scheme`, `hostname`, `username`/`password`, `port` and finally `hostname.lower().removesuffix(".")` against the allowlist with `==`. Never use `in` on the hostname: `docs.example.com.attacker.example` contains your domain.
---
For reference definitions, use a multiline pattern such as `re.compile(r"^ {0,3}\[[^\]]+\]:[ \t]*<?([^\s>]+)>?.*$", re.MULTILINE)` with `sub` and return `""` for lines you drop. For the one-pass part, compile **one** pattern with `re.IGNORECASE` and alternatives in this order: autolink `<(https?://[^>\s]+)>`, image, link, HTML tag `</?[a-z][^>]*>`, bare URL. The engine tries the alternatives left to right at each position, so `<https://...>` is an autolink, not a tag, and a URL inside `[text](url)` is consumed by the link alternative before the bare-URL one sees it.
---
Give the image and link alternatives groups for the text and the URL; in the `sub` callback, `match.groups()` returns `None` for unmatched groups, so test `autolink_url is not None`, then `image_alt is not None` (an empty alt is `""`), then `link_text is not None`, then `text.startswith("<")` for HTML, and treat the rest as a bare URL. To strip an allowed image's query, rebuild it as `https://` + hostname + path. `html.escape(value, quote=False)` and `html.escape(value)` cover both HTML contexts; `urllib.parse.quote(value, safe="!~*'()")` matches `encodeURIComponent`.
