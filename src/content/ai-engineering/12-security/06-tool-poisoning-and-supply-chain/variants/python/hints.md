Collect the texts first: `[{"location": "description", "text": tool.get("description") or ""}]` plus one entry per property of `tool["inputSchema"].get("properties", {})` that has a string `"description"`. Then run the five rules over each text. Patterns to start from: `re.compile(r"<\s*/?\s*(?:important|system|instructions?|secret|admin)\b[^>]*>|<!--[\s\S]*?-->", re.IGNORECASE)` for tags and `re.compile(r"~/\.ssh|id_rsa|\.env\b|mcp\.json|\.aws/credentials|/etc/passwd", re.IGNORECASE)` for paths.
---
Python strings are sequences of code points, so the invisible-character class can hold `\U000e0000-\U000e007f` directly and the excerpt is `f"U+{ord(match.group(0)):04X}"`. For shadowing, escape each name with `re.escape` and wrap it in `(?<![\w-])` and `(?![\w-])` (with `re.ASCII`), so `send_email` does not match inside `send_email_v2`.
---
`json.dumps(tool, sort_keys=True, separators=(",", ":"), ensure_ascii=False)` sorts keys at every depth and writes the same text as `JSON.stringify` of a canonical copy. In the gate, keep a copy of `pins` and the seen names (an ordered `dict.fromkeys(...)` works as an ordered set) on the instance; in `review`, add this list's names before scanning, then compute findings and hash per tool and follow the four cases in order.
