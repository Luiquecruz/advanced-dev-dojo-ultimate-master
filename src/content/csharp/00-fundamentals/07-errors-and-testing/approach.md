1. Read each requirement as a guard: what input must the method refuse, and how? `Parse` refuses bad text and out-of-range numbers by throwing, `Add` refuses blank and repeated names, and `Find` answers a missing name with `(false, 0)` instead of throwing.
2. `Ages.Parse` uses `int.TryParse` rather than `int.Parse`. Bad text is expected input here, and `int.Parse` would answer it with a `FormatException`, the wrong type. When `TryParse` returns `false`, the method throws `ArgumentException` with the parameter name, `nameof(text)`.
3. The range check comes second, because it needs the parsed number. A value below `0` or above `150` throws `ArgumentOutOfRangeException`. Since that type derives from `ArgumentException`, using it for the first case too would satisfy `Assert.Throws<ArgumentException>`; the test also compares `GetType()`, so each case needs its own type.
4. For `CountAdults`, run the tests first: the report names `IndexOutOfRangeException` and its message. Pressing **Run** prints the full exception, and its first `at` line is `Ages.CountAdults`. In that method the only array access is `ages[i]`, so the loop lets `i` reach an invalid index. With `i <= ages.Length` the last pass reads index `Length`; changing `<=` to `<` fixes it and leaves the rest of the method as it was.
5. The `SignUpList` constructor is a guard clause plus one assignment: `string.IsNullOrWhiteSpace(eventName)` covers `null`, `""` and spaces, and `EventName = eventName.Trim();` stores the clean name. Strings are immutable, so the result of `Trim` must be stored. `EventName { get; }` can only be set here; `Count { get; private set; }` can be changed by the class's own methods.
6. A private helper, `KeyOf(name) => name.Trim().ToLowerInvariant()`, gives `Add` and `Find` the same key, so `" Ana "` and `"ANA"` meet in the dictionary. `Add` checks the name, then `ContainsKey`, then calls `Ages.Parse`, and only when all three pass does it write `_ages[key]` and add one to `Count`. Any exception therefore leaves the object as it was.
7. `Find` calls `TryGetValue`, which returns `false` instead of throwing `KeyNotFoundException`, and turns its two results into the tuple `(true, age)` or `(false, 0)`. `Adults` visits every pair with `foreach (var (name, age) in _ages)` and counts the ages of `18` or more.
