1. Start from the parser, the hot path of any import. A `ReadOnlySpan<char>` is a window over characters that already exist, so slicing and trimming it cost nothing; the only allocation left is the SKU string the result must hold. Keep the error cases explicit: a missing comma or an empty SKU throws before `int.Parse` runs.
2. Build `SumQuantities` on top of `Parse`, walking the text with `IndexOf` and slicing instead of `Split('\n')`, which would create one string per line just to read them once. Decide what a blank line is (whitespace only, which covers a lone `'\r'`) and skip it.
3. Use `StringBuilder` where text grows in a loop. Each `+=` on a string copies everything written so far; `Append` writes into one growing buffer, and `ToString()` copies once at the end.
4. Treat the rented buffer as borrowed. The pool decides its real length and what is still inside it, so the only trustworthy numbers are the size you asked for and the count `Read` returns. The test pool hands out a longer array full of 0xFF to make that visible.
5. Give the buffer back in `finally`, so an exception from the stream cannot leak it, and give it back exactly once: a second `Return` would let two callers share one array. The last test drops the connection halfway through to check both.
