3. `split_evenly`: compute the share with floor division and the remainder with `%`, then return both, separated by a comma.
4. `format_cents`: convert cents to euros only inside the f-string, and let the format `:.2f` produce exactly two decimals.
5. `kind_of`: ask the value for its type and return the type's name.
6. `print_receipt`: reuse `line_total` and `format_cents`, print the two lines, and let the function end without `return`, so it gives back `None`.
