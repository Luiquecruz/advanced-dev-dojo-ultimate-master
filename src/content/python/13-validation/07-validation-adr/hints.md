Start with the numbers. A day has 86 400 seconds, so the gateway rate is the daily volume divided by that, rounded to an integer. For the schema documents, count how many versions of one event type are accepted at the same time (acceptance window divided by release cadence), then multiply by the event types.

The largest legitimate body is the lines times their size plus the envelope; the limit sits between that and twice that. For the models: a `TypedDict` or a dataclass validates nothing, so only one edge choice parses partner payloads; inside, the object must be typed and must not change after parsing.
