Start from the day: `var requestsPerDay = input.DailyActiveUsers * input.RequestsPerUserPerDay;`. Every QPS value is "something per day" divided by `SecondsPerDay` (86,400), never by 3,600 (seconds in an hour) or 1,440 (minutes in a day).
---
Keep `requestsPerDay` unrounded and derive each QPS from it with its own `Math.Ceiling`: `(long)Math.Ceiling(requestsPerDay * input.PeakFactor / SecondsPerDay)`. Rounding the average first and then multiplying gives `2316` instead of `2315` in the tests.
---
Round the writes per day once, half up, with `(long)Math.Floor(requestsPerDay * input.WriteRatio + 0.5)` (it is a count, and `0.1` is not exact in floating point), then multiply it by bytes, days and replicas. Plain `Math.Round` does not fit here: it rounds a half to the even number, so `Math.Round(500.5)` is `500`. For `FormatBytes`, copy the count into a `double` first (`double value = bytes;`, so dividing does not truncate), keep `string[] Units = ["B", "KB", "MB", "GB", "TB", "PB"]` and loop with `while (value >= 1000 && unit < Units.Length - 1)`, then round with `Math.Floor(value * 10 + 0.5) / 10` and print the result with `ToString(CultureInfo.InvariantCulture)` (add `using System.Globalization;`), which writes `1000` without a trailing `.0`.
