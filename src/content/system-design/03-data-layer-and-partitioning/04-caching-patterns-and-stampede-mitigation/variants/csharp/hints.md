Keep a second dictionary next to the entries: `Dictionary<string, Task<TValue>> _inFlight` maps a key to the task of its running load. On a miss, `await` the task already in the dictionary when there is one; otherwise call `_load(key)`, put the task it returns in the dictionary, and only then `await` it. An `async` method runs without pausing up to its first `await` of an unfinished task, so the 99 calls that arrive before the load finishes all find the same task.

Handle the end of the load in the call that started it: wrap `await loading` in `try`/`catch`. On success, compute the expiry with `_now() + _ttlMs + (long)Math.Floor(_random() * _jitterMs)` and store the entry; in the `catch`, store nothing and `throw;` again. Both remove the key from `_inFlight`, and every caller awaiting the same task gets its value or its exception. Keep the registration before the `await`: when `load` returns a task that is already complete, `await` does not pause at all, so everything after it runs before `GetAsync` returns.
