`ScopeKey` is one line: `JsonSerializer.Serialize(new[] { tenant, model, systemPrompt })` (the starter already has `using System.Text.Json;`). The starter's `Store` already keeps `CacheEntry(Scope, Vector, Answer)` records with the vector computed once, so `Lookup` only has to compare vectors, never prompts.
---
In `Lookup`, keep only the entries with `entry.Scope == scope`, embed the prompt once, and walk the candidates while remembering the best similarity so far (update it only with `>`, so the first entry wins a tie). Compare that best similarity with the threshold after the loop: returning the first entry above the threshold misses a better one stored later.
---
In `CompleteAsync`, loop over the providers and wrap only `answer = await provider.CallAsync(request);` in `try`. Catch with an exception filter, `catch (Exception error) when (IsRetryable(error))`, so any other exception is never caught and reaches the caller at once; `IsRetryable` is `error is TimeoutException or ProviderException { Status: 429 or (>= 500 and <= 599) }`. Inside the `catch`, remember the error as `lastError` and `continue`. After a successful call, store the answer and return it with `provider.Name`. After the loop, `throw lastError;`.
